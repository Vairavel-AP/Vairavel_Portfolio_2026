# Vairavel . A — Portfolio

## Files
- `index.html` — Main portfolio page
- `style.css` — All styles and dark theme
- `script.js` — Scroll animations, mobile menu, nav highlight

## Setup
1. Add your photo as `profile.jpg` in the same folder.
2. Open `index.html` in a browser — done!
3. Update GitHub, LinkedIn, Portfolio, Codolio links in index.html.

## Sections
- Hero (Profile Photo + Role Tags)
- Education
- Skills (6 categories)
- Projects (4 cards)
- Internships (2 cards)
- Experience & Leadership (timeline)
- Certifications & Achievements
- Footer

## Hosting (Free)
- **GitHub Pages**: Push to GitHub repo → Settings → Pages → Deploy from main branch
- **Netlify**: Drag and drop the folder at netlify.com
- **Vercel**: Import GitHub repo at vercel.com
